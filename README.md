# ORBIT // CODE — 軌道守護者

**Mobile Drawer Focus V1.14** · 傅立葉圓周軌道益智遊戲 · 繁體中文

🎮 **[立即遊玩（GitHub Pages）](https://qookey109-pixel.github.io/orbit-guardians/)**

## 遊戲規則

- **三顆星球 × 每顆六關，共 18 關**；單關最多使用 **3 個圓**
- 玩家調整圓數、半徑及順／逆旋轉方向；轉速固定為 1×、2×、3×，起始角度為 0°
- 可直接在遊戲畫面用滑鼠或觸控拖曳半徑，也能使用控制面板調整
- 綠色物資訊號可任意順序收集，同一訊號不會重複計分
- 命中半徑約 8～10 世界座標單位；碰撞紅色禁區會累積次數和顯示警示，但不扣除時間
- **不限時間**：沒有倒數、時間條或逾時失敗，可自由調整軌道直到完成
- **通關不中斷**：收齊補給後軌道持續運轉；沒有結算面板或星級評分，電腦顯示一個小型「下一關」浮動按鈕，手機在底部操作列顯示「下一關」
- 純前端 HTML / CSS / JavaScript，無付費 API、無伺服器

## 發布

`index.html` 為遊戲主頁，GitHub Actions 的 `Deploy GitHub Pages` 工作流程會在 main 分支更新時自動部署。

如果第一次部署尚未啟用 Pages，請在 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

## 一體式沉浸遊玩

- **主遊戲畫布全視窗鋪滿**：宇宙背景、飛船、軌道、補給站使用同一個舞台，不再有圍繞棋盤的側欄與區塊式頁面。
- **HUD 覆蓋式排版**：任務與補給紀錄放在上緣、三顆星球與每顆六關直接浮在畫面上方、發射／暫停／重設／預測集中下緣。
- **可收合的軌道儀表**：右側以輕透背景放置圓數、半徑與方向；可按右上「軌道控制」切換顯示，不需離開遊戲。
- **手機一面式**：主畫布全屏保留，底部「軌道設定」與「選擇關卡」採浮動抽屜；發射／重設／預測按鈕保持橫排。
- **全螢幕切換**：提供 ⛶ 按鈕，依瀏覽器是否支援 Fullscreen API 運作。
- **遊戲資料保留**：維持三顆星球十八關、V0.8 無時間限制與持續飛行；V0.9 舊星級資料保留在瀏覽器，但 V1.7 起暫停顯示與產生新星級。

## 單畫面操作

- 電腦版由同一個滿版宇宙場景承載星球切換、關卡 HUD 與圓周控制，不需捲動整頁。
- 手機版將設定與關卡改為底部按鈕切換的浮動面板，面板內可捲動、主頁不捲動。
- 支援窄螢幕與橫向手機；保留半徑拖曳、示範參數、關卡進度與原始解謎規則。

## V0.9 遊玩與成績（歷史功能，部分已在 V1.7 停用）

- **輕量引導**：新玩家第一次開啟約 7.5 秒、三個步驟（辨認補給站 → 理解預測路線 → 發射）；可立即跳過且不再顯示，不會遮住整個畫面。
- **明確目標與關卡敘事**：每關顯示應收集的補給站數量及短敘事；被鎖定關卡可點擊查詢解鎖前置條件。
- **路線與收集回饋**：預測線包含方向箭頭，靠近障礙的段落改以紅色顯示；收集補給時顯示擴散光環與 +1，實際飛行保留較短的軌道殘影。
- **非遮罩式通關成果**：右側控制台顯示星級、使用圓數、碰撞次數，以及「下一關」與「再試一次」。手機版保持底部下一關操作。過關後飛船繼續運轉。
- **星級（不計時間）**：無碰撞 3 星、1 次碰撞 2 星、2 次以上 1 星；使用示範參數最多 2 星。單圓通關追加「單環達人」標記。
- **儲存**：沿用 `orbit-code-progress` localStorage，除了已解鎖和已完成狀態，也保存每關最佳星級、碰撞數與圓數。成績以星級為先，平手再比較碰撞數和圓數，不會被較差重玩成績覆蓋。
- **無失敗時間壓力**：不倒數、不逾時、碰撞不扣秒；可隨時暫停、繼續與重新試跑。

## 星球探索與後續動畫

| 星球 | 關卡 | 視覺 | 學習主題 |
| --- | --- | --- | --- |
| 艾瑞斯（Origin） | 01–06 | 原版藍紫星空、殖民地 | 單環、雙環、順逆轉、三環與禁區 |
| 霜環星（Frost） | 07–12 | 冰藍極光、帶環星球 | 多環逆轉、冰層曲線、雙禁區 |
| 赤曜星（Ember） | 13–18 | 暖紅星雲、赤色星球 | 交錯頻率、三圓禁區與終章 |

- 每顆星球的畫面下方有獨立的 **6 關**，用「星球選擇」在已解鎖星球間切換；手機在「選擇關卡」底部抽屜內切換。
- 完成上一顆星球的第 6 關，即解鎖下一顆。切關不彈出遮住飛船的視窗；飛船在通關後仍持續運轉，玩家自行點擊「前往下一顆星球」。
- 舊版六關的解鎖及最佳成績使用相同 localStorage keys 和 flat level indices。舊資料中若第六關已完成但 unlocked=6，會自動開放第七關。
- **動畫留待後續加入**：跨星球時觸發 `orbit:planet-arrival` CustomEvent，其 `detail` 為 `{from,to,name}`（從 0 起算的星球索引）；之後可接入玩家製作的過場動畫，而目前直接切關。
- 不增加付費 API 或額外伺服器，維持 GitHub Pages 及 V0.8 無倒數的自由探索玩法。

## V1.14｜Mobile Drawer Focus：手機浮動面板一觸收合

- **點擊背景即可關閉**：手機開啟「軌道設定」或「選擇關卡」時，畫面外側顯示極輕的深藍遮罩；點擊遮罩直接收起面板，而不是必須再次點底部按鈕。

- **原本操作保持不變**：底部工具列、右上控制按鈕、Esc 收合、已解鎖關卡選定後自動收合、桌面版右側控制台都繼續沿用 V1.13 設計。跨 860px 斷點會自動恢復桌面模式。
- **V1.14 回歸測試**：針對兩種面板檢查背景點擊收合、展開狀態及關卡／半徑不變；CI 增加 `pull_request` 觸發，確保改動可在合併前接受瀏覽器測試。
- 不變：**3 星球／18 關、最多三圓、無倒數、通關不中斷、舊遊玩資料與獨立研究試玩室**。

- **手機點擊尺寸**：圓分頁、圓數增減、方向鍵與精密微調展開列維持約 40px 以上觸控高度；所有尺寸仍維持單一 Canvas 主畫面和原本固定版面。

## V1.12｜Level Review Lab：難度評估、相似度檢查與獨立試玩

- **[獨立候選試玩室](https://qookey109-pixel.github.io/orbit-guardians/lab/)**：預載 3 份由 seed `20261011` 生成的 Hard 研究候選；可以直接切關、調整最多三個圓、半徑與方向、發射、重試、開關預測路線或載入參考解法。另可匯入候選產生器輸出的 JSON。
- **人工評審與匯出**：可標記「可採用／待修改／不採用」、填寫備註並匯出評審 JSON。評審紀錄只寫到獨立 `orbit-lab-reviews-v1` 本機儲存鍵，不會修改正式遊戲的 `orbit-code-progress`、解鎖紀錄或關卡資料。
- **規則式品質分析**：[候選品質工具](tools/level-quality.mjs) 計算起始配置命中目標數、圓周方向變化、路徑變化、目標空間分布、參考解法禁區餘裕與 0–100 挑戰指數，並提供 Easy／Medium／Hard／Expert 的**預估級距**。此指數不是經玩家成功率校準的客觀難度；仍需真人試玩。
- **相似度與重複檢查**：比較候選和正式 18 關及本批已接受的研究候選，包括圓周形狀、方向、半徑、目標時間與禁區位置。近似度達門檻的候選需重新生成；這是啟發式篩查，不保證題型獨特或有趣。
- **獨立審核門檻**：新的 `tools/test-level-review-lab.mjs` 驗證展示候選可用固定 seed 重新產出、幾何無禁區碰撞、品質指數一致，並拒絕極近似候選。GitHub Actions 同時執行正式 18 關、生成器及試玩室桌面／手機操作驗收。
- **不自動發布**：新關卡只以研究檔案或 [試玩室](lab/) 呈現，**並未加入正式三顆星球／18 關**。即使選「可採用」，也不會執行 GitHub 寫入或部署。
- **可重現命令**：

  ```bash
  node tools/verify-orbit-levels.mjs
  node tools/test-level-workshop.mjs
  node tools/test-level-review-lab.mjs
  node tools/generate-level-candidates.mjs --seed 20261011 --difficulty hard --count 3 --output research/candidates.json
  ```

## V1.10｜原生 Canvas 動畫與獨立幾何檢查

- **路線預測重啟**：玩家將「路線」由關切換成開，預測路徑會在 520ms 內顯示短暫的逐段描繪微光；原本的完整路線、方向與紅色危險區段從第一幀即保留，不會因動效失去可讀性。
- **半徑數字回饋**：滑桿、拖曳、輸入與微調仍即時改變實際解謎參數。數字標籤另用瀏覽器原生 Web Animations API 呈現短暫高亮，最多每 110ms 觸發一次；不引入 Anime.js 或下載任何字體/套件。
- **選圓無障礙語意**：將選圓的按鈕狀態統一為 `aria-pressed`，避免混用 `role=button` 與 `aria-selected`。保留最多三個圓與半徑 0–165。
- **純 Node.js 關卡獨立驗證**：新增 [`tools/verify-orbit-levels.mjs`](tools/verify-orbit-levels.mjs)，GitHub Actions 在跑瀏覽器前，獨立計算 18 關參考圓周的路徑、補給命中與禁區接觸。工具不使用遊戲裡的 `collision()` 或 `__ORBIT_DEBUG__` 來直接宣告過關。
- **降低動態設定**：保留 `prefers-reduced-motion` 支援，所有動畫只改視覺、不改判定。
- 你提供的 Anime.js 片段屬於 SVG／DOM 參考；ORBIT 現在用 Canvas 2D，不適合直接套用 `strokeDashoffset`。外部動畫函式庫與 3D 模型先保持未導入。

## V1.6｜星際探索進度與接續遊玩

- **接續上一關**：瀏覽器在既有 `orbit-code-progress` 內額外保存 `lastLevel`，下次開啟時自動進入上次遊玩的已解鎖關卡。舊版未含 `lastLevel` 的紀錄仍從第一關開始，原有星級／解鎖內容保持不變。
- **真正的星球切換**：按下已解鎖的星球，不再只替換上方關卡文字，而會直接切換到該星球的第一個尚未完成、已解鎖關卡；若整顆星球已完成，則前往該星球最後一關。軌道、場景色彩及關卡選單同步切換。
- **星際進度 HUD（歷史設定）**：最初包含 `已完成關卡 / 18` 與 `最佳星級總數 / 54`；V1.7 已移除星級，只保留完成關卡進度；每顆星球的縮圖外圈也依 0～6 關進度點亮。手機版關卡按鈕附上簡短進度數字，詳細進度位於原本的關卡抽屜內。
- 通關後更新已完成關卡及星級，保存最佳成績時不會被較差紀錄覆蓋；未增加新面板、倒數或強制動畫。
- 18 關、三顆星球、無限時、手把操作、星球解鎖徽章、航線參數分享及你之後的正式過場動畫接口均保留。

## V1.5｜星球旅程與手把控制

- **星球解鎖儀式感**：首次完成艾瑞斯／霜環星的最後一關時，會浮出對應的星球徽章和約 4.8 秒的成就提示。右側通關成果也顯示下一顆星球的名稱。提示不遮住遊戲、不停止飛船；同一星球重玩不重複觸發解鎖事件。
- **保留你之後的過場動畫空間**：新事件 `orbit:planet-unlocked` 僅在第一次解鎖時發出，`detail={from,to,name,level}`（星球索引由 0 起算），原有 `orbit:planet-arrival` 則仍在玩家主動前往下一顆星球時發出。兩者分離，方便日後插入你的動畫，現在不強制播放轉場。
- **手把支援**：瀏覽器提供標準 Gamepad API 且遊戲視窗可接收到手把時，可以 A 發射／暫停、B 切換旋轉方向、LB/RB 選圓、十字鍵左右半徑 ±1、上下 ±5，左搖桿橫向連續微調，X 切換預測、Y 重試、Start 在通關後前往下一關。連接時自動顯示一行快捷提示，拔除後隱藏。
- 保持原本三顆星球 18 關、單一全畫面 HUD、不限時間、過關不中斷、所有 localStorage 的星級和參數分享相容；無 API 費用或登入需求。

## V1.4｜飛行回饋與航線分享

- **自選短音效**：在「進階選項」開啟／關閉音效（初次預設關閉），使用瀏覽器 Web Audio 即時合成發射、補給成功、禁區警告及通關的短提示；不下載音樂、不播放 BGM，偏好儲存在本機。
- **分享航線**：點「↗ 分享航線」複製目前星球／關卡與最多三個圓的半徑、方向參數連結。參數存在網址的 `stage`、`orbit` 查詢值，不傳送到伺服器、不包含玩家成績。收到連結的人需要先解鎖對應關卡，連結不能跳過進度門檻。
- **收集與碰撞視覺回饋**：收集補給時，進度數字短暫亮起；撞到紅色禁區時，危險中心出現紅色擴散光環，碰撞數也短暫亮起；遵守「減少動態效果」系統偏好。
- **非遮罩式操作提示**：分享成功、分享連結遭鎖定等狀態以短暫的小型 HUD 訊息呈現，不遮住遊戲或中斷軌道。
- 原本的 18 關、三星、獨立最佳成績、上次參數、無倒數及持續飛行行為全部保留。
