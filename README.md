## V1.23｜Flight Paint Cache：高圈數描線與 Safari 效能收斂

- **停止時不做無意義全畫布重繪**：動畫影格仍排程以支援開始／暫停，但非運轉／手繪時不再每影格清空整張 Canvas。滑桿、操作、模式切換與視窗 resize 仍即時觸發需要的描畫。
- **真實運動路徑保留**：原始手繪線與正在增加的金色尾跡，使用可累積的原生 Path2D 畫筆資料；每個新增採樣點延長路徑，不需每個影格重新生成數千個 CSS 座標物件。反向／循環開放線條、重新生成與 resize 會正確更新快取。
- **高圓周數繪圖最佳化**：256–2048 個傅立葉圓仍全部參與幾何演算，但 Canvas 僅配置必要的 30 個左右骨架物件，並用最終完整圓鏈末端位置畫太空船／追蹤端點。高圈數可見性與畫線幾何不變。
- **背景觀測場重用**：固定尺寸的 Canvas 漸層只建立一次，與格線快取一同避免每影格產生額外渲染物件。瀏覽器背景／前景切換清空上一影格時間基準以減少恢復時跳動。
- **跨引擎 QA**：Chromium 與 Playwright WebKit 加上暫停影格無重繪、背景漸層復用、手繪與金線 Path2D 持續復用、256 圈對比完整旋轉端點精度、手機與實驗／正式遊戲隔離；不宣稱未實施的 FPS 實測。
- **實機狀態**：使用者的 MacBook Neo 遠端裝置於此輪檢查時離線，因此尚未完成原生 macOS Safari 的實機驗收；雲端 WebKit 不等於實機結果。

## V1.22｜Precision Focus：量測層級 × 多圈可讀性 × 行動 Safari

- **淡化與可隱藏量測格線**：中央觀測台原有的 Path2D 格線按照手機與桌面尺寸使用 76／64／56 CSS px 間距；在手繪模式降低格線對比，讓原始青綠線與真正的金色動態軌跡成為視覺主角。進階設定新增「顯示量測格線」開關；關閉後不再繪製格線，但不改 Fourier 模型。
- **圓周骨架聚焦**：少圈維持逐一顯示，多圈依振幅展示主要旋轉圓，保證使用者選取的圓、最末圓及起始結構始終顯示，降低重疊線條；f=0 的 DC 平移向量不再畫成誤導性的旋轉圓。選取端點對比提高，所有圓依舊參與實際軌道計算。
- **手機操作可靠性**：只追蹤一個有效手指／觸控筆，利用瀏覽器 coalesced pointer events 補足快速滑動軌跡；完成才自動 FFT 生成，被系統取消或失去 pointer capture 的筆跡不能當完整路徑分析。手機表單／功能鍵補足 44px 觸控目標。
- **Canvas 記憶體防護**：高 DPR 畫布依可用視窗採取最多約 240 萬 backing pixels 的畫質預算，避免高解析度螢幕無必要地分配大畫布；不影響 CSS 世界座標或手繪邏輯。
- **CI 驗證**：保留正式 18 關與研究 Lab 隔離，新增 Grid toggle、格線快取、256 圈選取第 200 圈、取消手繪、coarse pointer 觸控熱區、高 DPR 像素預算與 Chromium／Playwright WebKit 雙引擎回歸。
- **注意**：Linux WebKit 自動化可抓跨引擎錯誤，但真實 macOS/iOS Safari 實機仍需人工確認手感與流暢度。

## V1.20｜手繪即生成：旋轉圓沿線描繪

- **真正的手繪優先流程**：切入「手繪軌跡」、畫出任何路線、放開滑鼠或手指，直接自動傅立葉分解、選擇必要圓數、開始播放；不必先選圈數或再按生成。
- **自動精度控制**：完整保留 2,048 組 FFT 係數，以低於約 2 CSS px 的 RMS 尾項誤差為起點、檢查轉折處偏差，通常自動使用 12–512 圈。呈現實際重建誤差，並保留手動圈數與各圈參數微調；增加圈數一定取得真實的頻率分量，不會添加虛構的預設圓。
- **開放路徑也能沿線運作**：自動辨識首尾接近的閉合線條。開放線採用「沿原線走完 → 沿線反向返回」的周期性重建，不再把起終點強行畫一條直線連起來。單圈周期因此對應一次來回。
- **動態軌跡線**：以旋轉圓鏈的真實末端座標逐步畫出一條金色實線，依時間插值避免快速移動時變成稜角直線；半透明虛線仍用來對照手繪，完整預測線則可於細節設定手動開啟。
- **簡化模式**：手繪時隱藏提前選圈數的欄位，保留播放與清空；自動完成後再出現圈數微調。尊重系統減少動態效果，不強制自動播放。
- **驗收條件**：Chromium 與 WebKit 真正滑鼠手繪、離開畫布後生成、即時動態描線、閉合與開放兩種線條、重建誤差、全頻譜圈數變更、手機不捲動、研究 Lab 與主遊戲進度隔離。

## V1.19｜ORBIT LAB 軌跡實驗室（獨立模式）

🧪 **[開啟軌跡實驗室](https://qookey109-pixel.github.io/orbit-guardians/experiment/)**

- **主站入口**：主遊戲右上角「實驗室 ↗」連結。研究用的 `/lab/` 是獨立關卡 Review Lab，**絕不覆蓋或更名**。
- **極簡單畫面**：頂部自由／手繪兩種操作、畫布、底部播放／圓數／速度；半徑、頻率、相位與軌跡顯示切換收進設定。
- **自由加圈**：輸入、增加、減少圓周數，當前實作的實務上限為 **2,048 個圓**（包含高圈數效能提醒）；可拖曳目前運行相位下的圓周端點，或輸入半徑 0–1,000、頻率 -2,048 至 +2,048、相位 -180° 至 180°。速度倍率可調。
- **手繪 → 自動生成**：滑鼠／觸控直接在 Canvas 繪製；以「含閉合段的等弧長取樣 → radix-2 FFT → 依幅度優先保留傅立葉係數 → 合成旋轉圓周」重建原路徑。起點附近自動閉合，開放線條的端點可能產生接縫；圈數越多，通常越接近原始輪廓。512／1,024／2,048 個採樣點依要求圈數調整。
- **生成後可以手動微調**：仍保留原線對照；改圈數、任一圓周半徑／頻率／相位，再即時重繪。
- **效能與存檔隔離**：軌跡預覽僅在參數或尺寸改變時重算，極高圈數會簡化中間圓周骨架繪製，所有圓仍參與軌跡計算。頁面不讀寫正式遊戲的 `orbit-code-progress` 或關卡資料。
- **測試**：`.github/workflows/experiment-smoke.yml` 的 Chromium／WebKit 雙引擎測試，檢查 FFT 圓形擬合、真正滑鼠手繪、自動生成、圓數調整、手機無捲動、減少動態效果、正式遊戲和研究 Lab 均可存取。

## 遊戲規則

- **三顆星球 × 每顆六關，共 18 關**；單關最多使用 **3 個圓**
- 玩家調整圓數、半徑及順／逆旋轉方向；轉速固定為 1×、2×、3×，起始角度為 0°
- 可直接在遊戲畫面用滑鼠或觸控拖曳半徑，也能使用控制面板調整
- 綠色物資訊號可任意順序收集，同一訊號不會重複計分
- 命中半徑約 8～10 世界座標單位；碰撞紅色禁區會累積次數和顯示警示，但不扣除時間
- **不限時間**：沒有倒數、時間條或逾時失敗，可自由調整軌道直到完成
- **通關不中斷**：收齊補給後軌道持續運轉；沒有結算面板或星級評分，電腦顯示一個小型「下一關」浮動按鈕，手機在底部操作列顯示「下一關」
- 純前端 HTML / CSS / JavaScript，無付費 API、無伺服器

## 一體式沉浸遊玩

- **主遊戲畫布全視窗鋪滿**：宇宙背景、飛船、軌道、補給站使用同一個舞台，不再有圍繞棋盤的側欄與區塊式頁面。
- **HUD 覆蓋式排版**：任務與補給紀錄放在上緣、三顆星球與每顆六關直接浮在畫面上方、發射／暫停／重設／預測集中下緣。
- **可收合的軌道儀表**：右側以輕透背景放置圓數、半徑與方向；可按右上「軌道控制」切換顯示，不需離開遊戲。
- **手機一面式**：主畫布全屏保留，底部「軌道設定」與「選擇關卡」採浮動抽屜；發射／重設／預測按鈕保持橫排。
- **全螢幕切換**：提供 ⛶ 按鈕，依瀏覽器是否支援 Fullscreen API 運作。
- **遊戲資料保留**：維持三顆星球十八關、V0.8 無時間限制與持續飛行；V0.9 舊星級資料保留在瀏覽器，但 V1.7 起暫停顯示與產生新星級。

## V0.9 遊玩與成績（歷史功能，部分已在 V1.7 停用）

- **輕量引導**：新玩家第一次開啟約 7.5 秒、三個步驟（辨認補給站 → 理解預測路線 → 發射）；可立即跳過且不再顯示，不會遮住整個畫面。
- **明確目標與關卡敘事**：每關顯示應收集的補給站數量及短敘事；被鎖定關卡可點擊查詢解鎖前置條件。
- **路線與收集回饋**：預測線包含方向箭頭，靠近障礙的段落改以紅色顯示；收集補給時顯示擴散光環與 +1，實際飛行保留較短的軌道殘影。
- **非遮罩式通關成果**：右側控制台顯示星級、使用圓數、碰撞次數，以及「下一關」與「再試一次」。手機版保持底部下一關操作。過關後飛船繼續運轉。
- **星級（不計時間）**：無碰撞 3 星、1 次碰撞 2 星、2 次以上 1 星；使用示範參數最多 2 星。單圓通關追加「單環達人」標記。
- **儲存**：沿用 `orbit-code-progress` localStorage，除了已解鎖和已完成狀態，也保存每關最佳星級、碰撞數與圓數。成績以星級為先，平手再比較碰撞數和圓數，不會被較差重玩成績覆蓋。
- **無失敗時間壓力**：不倒數、不逾時、碰撞不扣秒；可隨時暫停、繼續與重新試跑。

## V1.17｜WebKit Flight Performance：軌道預測快取與 Safari 相容性

- **預測線原生 Path2D 快取**：靜止／暫停時，針對同一關卡、圓周配置、運行相位與畫面尺寸，重用完整 240 段預測點、禁區分類、實際繪製路徑與方向箭頭；不再在每一幀重新計算三角函數及交會判定。飛行時位置持續變動，仍逐幀更新；改半徑／方向、切關或縮放立即重算。只保留一份快取，不累積歷史畫面。

- **手把支援**：瀏覽器提供標準 Gamepad API 且遊戲視窗可接收到手把時，可以 A 發射／暫停、B 切換旋轉方向、LB/RB 選圓、十字鍵左右半徑 ±1、上下 ±5，左搖桿橫向連續微調，X 切換預測、Y 重試、Start 在通關後前往下一關。連接時自動顯示一行快捷提示，拔除後隱藏。
- 保持原本三顆星球 18 關、單一全畫面 HUD、不限時間、過關不中斷、所有 localStorage 的星級和參數分享相容；無 API 費用或登入需求。

## V1.4｜飛行回饋與航線分享

- **自選短音效**：在「進階選項」開啟／關閉音效（初次預設關閉），使用瀏覽器 Web Audio 即時合成發射、補給成功、禁區警告及通關的短提示；不下載音樂、不播放 BGM，偏好儲存在本機。
- **分享航線**：點「↗ 分享航線」複製目前星球／關卡與最多三個圓的半徑、方向參數連結。參數存在網址的 `stage`、`orbit` 查詢值，不傳送到伺服器、不包含玩家成績。收到連結的人需要先解鎖對應關卡，連結不能跳過進度門檻。
- **收集與碰撞視覺回饋**：收集補給時，進度數字短暫亮起；撞到紅色禁區時，危險中心出現紅色擴散光環，碰撞數也短暫亮起；遵守「減少動態效果」系統偏好。
- **非遮罩式操作提示**：分享成功、分享連結遭鎖定等狀態以短暫的小型 HUD 訊息呈現，不遮住遊戲或中斷軌道。
- 原本的 18 關、三星、獨立最佳成績、上次參數、無倒數及持續飛行行為全部保留。
