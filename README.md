# ORBIT // CODE — 軌道守護者

**Guided Orbit V0.9** · 傅立葉圓周軌道益智遊戲 · 繁體中文

🎮 **[立即遊玩（GitHub Pages）](https://qookey109-pixel.github.io/orbit-guardians/)**

## 遊戲規則

- 共六關，每次最多使用 **3 個圓**
- 玩家調整圓數、半徑及順／逆旋轉方向；轉速固定為 1×、2×、3×，起始角度為 0°
- 可直接在遊戲畫面用滑鼠或觸控拖曳半徑，也能使用控制面板調整
- 綠色物資訊號可任意順序收集，同一訊號不會重複計分
- 命中半徑約 8～10 世界座標單位；碰撞紅色禁區會累積次數和顯示警示，但不扣除時間
- **不限時間**：沒有倒數、時間條或逾時失敗，可自由調整軌道直到完成
- **通關不中斷**：收齊所有補給後軌道持續運轉，不跳出遮住遊戲的結算視窗；桌機在右側控制台顯示「下一關」，手機於底部操作列顯示「下一關」
- 純前端 HTML / CSS / JavaScript，無付費 API、無伺服器

## 發布

`index.html` 為遊戲主頁，GitHub Actions 的 `Deploy GitHub Pages` 工作流程會在 main 分支更新時自動部署。

如果第一次部署尚未啟用 Pages，請在 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

## 單畫面操作

- 電腦版同一個畫面呈現遊戲棋盤、六關切換與圓周控制台，無須捲動整頁。
- 手機版將設定與關卡改為底部按鈕切換的浮動面板，面板內可捲動、主頁不捲動。
- 支援窄螢幕與橫向手機；保留半徑拖曳、示範參數、關卡進度與原始解謎規則。

## V0.9 遊玩與成績

- **輕量引導**：新玩家第一次開啟約 7.5 秒、三個步驟（辨認補給站 → 理解預測路線 → 發射）；可立即跳過且不再顯示，不會遮住整個畫面。
- **明確目標與關卡敘事**：每關顯示應收集的補給站數量及短敘事；被鎖定關卡可點擊查詢解鎖前置條件。
- **路線與收集回饋**：預測線包含方向箭頭，靠近障礙的段落改以紅色顯示；收集補給時顯示擴散光環與 +1，實際飛行保留較短的軌道殘影。
- **非遮罩式通關成果**：右側控制台顯示星級、使用圓數、碰撞次數，以及「下一關」與「再試一次」。手機版保持底部下一關操作。過關後飛船繼續運轉。
- **星級（不計時間）**：無碰撞 3 星、1 次碰撞 2 星、2 次以上 1 星；使用示範參數最多 2 星。單圓通關追加「單環達人」標記。
- **儲存**：沿用 `orbit-code-progress` localStorage，除了已解鎖和已完成狀態，也保存每關最佳星級、碰撞數與圓數。成績以星級為先，平手再比較碰撞數和圓數，不會被較差重玩成績覆蓋。
- **無失敗時間壓力**：不倒數、不逾時、碰撞不扣秒；可隨時暫停、繼續與重新試跑。
